# AI-nki

Hide labels on lecture diagrams and study them in Anki. Try the built-in sample without an account, or connect an eligible ChatGPT Plus or Pro plan for AI suggestions.

[Try the interactive demo](https://stroudmj00.github.io/ai-nki/) · [Download the Windows add-on](https://github.com/Stroudmj00/ai-nki/releases/download/v0.6.15-preview/ai-nki-0.6.15-preview.ankiaddon)

In Windows Anki Desktop, open **Tools → Add-ons → Install from file**, select the download and restart Anki. Open **Tools → AI-nki → Try the sample**. Tested on Windows x64 with Anki Desktop 26.09.3.

[Report a problem](https://github.com/Stroudmj00/ai-nki/issues). Use the public sample to illustrate issues and keep personal lecture materials and account details private.
